# Product Management Dashboard

A responsive product management dashboard built using React and Tailwind CSS.

## Features
- List & Grid view toggle
- Real-time search with debounce
- Add & Edit product modal
- In-memory state management
- Pagination
- Empty state UI
- Responsive design

## Tech Stack
- React (Vite)
- Tailwind CSS
- JavaScript
